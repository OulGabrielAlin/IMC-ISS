Application for a micro-creditting institution - second (final) version.
Done as a lab project for ISS/SSE (Software Systems Engineering) course at the Faculty of Computer Science, UBB, Cluj-Napoca.
The application implements each use case presented in the UseCaseTables folder, alongside the sequence diagrams that can be found in the IMC.mdj file.

The final version of this project implements each workflow and use-case as illustrated in the UseCaseTables folder, alongside the sequence diagrams into a concrete Java project.
